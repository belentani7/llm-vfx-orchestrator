Referencia técnica · v0.2.0

Arquitectura, CLI y herramientas de verificación

LLM VFX Orchestrator combina un planificador interactivo de secuencias VFX en navegador (workspace.html) con el paquete asíncrono Python orchestrator (CLI vfp) para ejecutar renders en bucle cerrado sobre ComfyUI.

1. Arranque rápido

# Espacio de trabajo Web (React + TypeScript + Vite)
npm ci
npm run dev          # Abre http://localhost:5173/workspace.html
npm run build        # Genera el bundle estático en dist/

# Orquestador Python (Python >= 3.11)
pip install -e ".[dev]"
vfp init -o config.yaml
vfp templates
vfp run -p "retrato dramático a contraluz, 85mm" --dry-run
vfp run --batch sequence.vfp-batch.json --concurrency 4

2. Módulos del paquete Python (orchestrator/)

MóduloResponsabilidad
orchestrator/pipeline.pyMotor VFPPipeline: planificación, cola ComfyUI, evaluación visual QA, corrección iterativa, límite de presupuesto (max_job_cost_usd) y ejecución por lotes.
orchestrator/comfyui_client.pyCliente HTTP + WebSocket asíncrono con semáforo de concurrencia, reconexión y respaldo vía /history.
orchestrator/llm_agents.pyAgentes especializados (DirectorAgent, AssetGenerator, QAInspector, CorrectionAgent) con cadena de proveedores y fallback automático.
orchestrator/feedback_loop.pyDetección de oscilaciones y estancamiento de puntuación (plateau_patience) y aplicación recursiva de parches sobre grafos ComfyUI.
orchestrator/store.pyPersistencia atómica en disco (~/.vfp/jobs) para inspección y reintento determinista (vfp retry).

3. Herramientas internas de diagnóstico y auditoría (scripts/)

ComandoDescripción
python3 scripts/doctor.py [--json]Verifica las 50 reglas estructurales, gobernanza, manifiestos y metadatos HTML del repositorio.
node scripts/validate-catalog.mjsValida la coherencia entre data/catalogo.json, data/catalogo.mjs y el inventario medido.
node scripts/audit-web.mjs [--json]Audita HTML semántico, enlaces internos, ausencia de recursos externos bloqueantes, contraste WCAG AA, compilación GLSL y presupuesto de bundle.
python3 scripts/benchmark.pyMide el rendimiento y escalado concurrente del pipeline contra un servidor ComfyUI local simulado.
