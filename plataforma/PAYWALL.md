# Modelo de monetización — llm-vfx-orchestrator

## Regla dura
Ninguna capacidad del núcleo se reserva a un plan de pago. El producto base sigue siendo libre. El cobro ocurre únicamente en servicios opcionales alrededor del producto.

## Qué se paga
| Concepto | ¿Se cobra? | Qué incluye |
|----------|------------|-------------|
| Uso base | No | Código abierto, uso gratuito |
| Soporte | Sí | Asistencia prioritaria, SLA |
| Gestionado | Sí | Despliegue y mantenimiento |
| Consultoría | Sí | Integración y personalización |

## Estructura de pago
No hay paywall dentro del producto. Los pagos son por servicios opcionales de soporte, alojamiento y consultoría.
