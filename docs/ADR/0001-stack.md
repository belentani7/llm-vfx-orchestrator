# ADR 0001 — Stack y límites

- **Estado:** aceptado
- **Fecha:** 2026-11-10
- **Contexto:** el repositorio ya existe con el stack medido
  (Python, JSON, HTML, Markdown, TypeScript, CSS); cambiarlo no está en el alcance.
- **Decisión:** se conserva el stack y se añaden capas de documentación, marca y verificación
  sin tocar el código de producto.
- **Consecuencias:** el repositorio gana gobernanza y contrato; el producto no cambia de
  comportamiento en esta fase.
- **Alternativas descartadas:** reescritura completa (coste y riesgo sin beneficio medido);
  segundo repositorio espejo (duplica mantenimiento).
