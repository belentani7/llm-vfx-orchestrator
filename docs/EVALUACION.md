# Evaluación

## Indicadores

| Indicador | Cómo se mide | Umbral para decir «funciona» |
|---|---|---|
| Reglas en verde | `python scripts/doctor.py` | ≥ 90% de las evaluables |
| Cobertura de la promesa | módulos con prueba / módulos declarados | ≥ 1 probado |
| Frescura del dato | fecha en `docs/FUENTES.md` | ≤ 90 días |
| Accesibilidad | fallos ACC-* | 0 |

## Qué no mide esto

No mide si el producto sirve a una persona real. Eso exige una prueba con alguien
ajeno al proyecto; queda declarado como pendiente.
