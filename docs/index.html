VISUAL FEEDBACK PIPELINE / 2026 · RENDER INTELLIGENCE

La imagen se genera.
La calidad se decide.

VFP conecta agentes de lenguaje con ComfyUI para planificar un workflow, renderizar, inspeccionar los píxeles reales y corregir el resultado. Cuando la mejora no llega, escala a revisión humana en lugar de repetir indefinidamente.

01 / ARQUITECTURA

Un bucle cerrado.
Sin humo.

Los agentes no certifican calidad por intuición. El inspector recibe la imagen real del render; el pipeline conserva el estado del trabajo, mide el resultado y aplica un límite explícito de reintentos y concurrencia. Los errores de proveedor o los controles inconclusos no se convierten en un aprobado ficticio.

03 / INICIO REAL

De código a render.

Instala desde el repositorio autorizado. Copia la configuración sin claves reales, exporta credenciales en tu entorno y conecta una instancia de ComfyUI. La web es documentación: no ejecuta renders por sí misma.

TERMINAL / VFPLOCAL EXECUTION
# Desde el repositorio clonado
$ python -m pip install -e ".[dev]"
$ cp config.example.yaml config.yaml
# Exporta ANTHROPIC_API_KEY y DASHSCOPE_API_KEY
$ vfp doctor -c config.yaml
$ vfp plan --prompt "retrato cinematográfico" -o workflow.json
$ vfp run workflow.json -c config.yaml
$ vfp jobs

Este flujo requiere proveedores válidos y ComfyUI accesible; algunas órdenes fallarán si faltan. No se afirma que exista una instancia de GPU gratuita ni un servicio SaaS público asociado.

04 / UTILIDAD LOCAL · SIN SUBIDAS

Comprueba la estructura de un workflow.

Pega JSON en formato API de ComfyUI. Esta comprobación ocurre solo en tu navegador: no guarda, transmite, renderiza ni certifica compatibilidad con modelos o nodos instalados. Máximo 256 KiB y 1024 nodos.
