Capabilities

Built for disciplined shot production, not random prompt roulette.

Every shot inherits global Visual Bible rules while keeping camera, movement, lighting, negative constraints, and render cost explicit.

PLANNER

Shot-by-Shot Continuity Lock

Maintain a global Visual Bible and per-shot framing, lens, movement, lighting, seed, and continuity notes stored locally in your browser.

COST CONTROL

Pre-Render GPU & QA Budgeting

Estimate frames, VRAM tier (12/16/24 GB), expected QA passes, and USD budget per shot before dispatching expensive GPU jobs.

EXECUTOR

Async ComfyUI HTTP + WebSocket

Queue node graphs, follow live WebSocket progress with HTTP history fallback, and bound concurrent GPU renders via semaphores.

CLOSED-LOOP QA

Vision Inspection & Auto-Correction

Inspect rendered frames with multimodal LLMs, patch workflow parameters automatically, and escalate cleanly on score plateaus or cost caps.

MULTI-PROVIDER

Resilient Provider Chains

Route Director, Asset, QA, and Correction roles across Anthropic, OpenAI-compatible, DashScope/Qwen-VL, Zhipu/GLM, or local Ollama endpoints.

REGISTRY

Atomic Job Store & Manifest Export

Export deterministic JSON manifests or vfp run --batch specs, and inspect every persisted iteration via vfp jobs.

Closed-Loop Architecture

Four deterministic stages from storyboard to approved plate.

The browser workspace and Python orchestrator package share structured JSON contracts so creative planning and automated rendering never drift.

01 · PLAN

Browser Shot Workspace

Author the Project Bible, sequence EDL, lens language, and continuity anchors in workspace.html.

02 · DIRECT

Workflow Synthesis

Export a .vfp-batch.json spec or invoke DirectorAgent with any of the 6 YAML templates.

03 · RENDER & QA

ComfyUI + Vision Gate

ComfyUIClient renders frames and QAInspector scores output fidelity against qa_threshold.

04 · CONVERGE

Patch or Escalate

FeedbackLoop applies targeted node corrections until approved, plateaued, or capped by budget.

Quickstart

Run in the browser or install the Python CLI in 30 seconds.

Zero API keys required for shot planning. Connect ComfyUI and your preferred local or cloud LLM when ready to render.

1. Browser Shot Planning Workspace

npm ci
npm run dev
# Open http://localhost:5173/workspace.html
# Run full verification & web audit:
npm test && npm run build && npm run audit:web

2. Python Closed-Loop CLI (vfp)

pip install -e ".[dev]"
vfp init -o config.yaml
vfp templates
vfp run -p " dramatic backlit portrait, 85mm " --dry-run
vfp run --batch sequence.vfp-batch.json --concurrency 4
